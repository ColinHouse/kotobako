# 头三件事

1. **设置 → 词典 → 安装 JMdict**（约 25 MB）。不装的话，收件箱里点词查不到释义。
2. **作品 → 添加一部** → 开始会话。
3. **采集 → 接上 Textractor**。给 Textractor 装一次 WebSocket 扩展（它不随 Textractor
   自带），采集页的「Hook 文本源」就会从「未检测到」变成「已连接」。不想装扩展的话，
   让 Textractor 把台词复制到剪贴板，在同一页打开「剪贴板监听」。
   协议细节见 [Hook 协议](/integrations#hook-协议)。

## 之后的日常

台词从 Hook 进来 → 收件箱点词建卡 → 复习页复习。

这个游戏勾不到、剪贴板也没接上时，采集页的「手动粘贴」可以直接把一句话存进来——
它不是摆设，是这一版唯一的兜底。

台词也可以整批导入：[字幕、EPUB 或 mokuro 漫画](/integrations#把文本导入一部作品)。
字幕配上本地视频还能为每一句切出原声与截图。

## 为什么没有屏幕识别

第一版不提供屏幕识别（OCR）。它需要一套还不存在的框选体验，准确度也还没调到能用，
先发出来只会让人觉得整个软件不可靠。引擎、接口和已经识别过的句子都还在，只是界面上
不提供——什么时候打开见 [#192](https://github.com/ColinHouse/kotobako/issues/192)。

也就是说：**实时采集的句子没有截图。** 需要截图的话，走字幕 + 本地视频那条路。
